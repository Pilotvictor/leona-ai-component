# Leona AI component

Ficheiros do componente opcional **Leona IA**, descarregados automaticamente pela aplicação Leona Compressor
(níveis de compressão «IA Máximo / Equilibrado / Rápido»). **Não é para uso manual:** a Leona descarrega e verifica
(SHA-256) os anexos da secção *Releases*.

Files of the optional **Leona AI** component, downloaded automatically by the Leona Compressor application.
Not meant for manual use: the app downloads and verifies (SHA-256) the assets in *Releases*.
